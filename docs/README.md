# StockFlow Documentation

Cette documentation accompagne directement le code source de StockFlow.

## Objectif

Centraliser les décisions, fonctionnalités existantes et fonctionnalités reportées afin de pouvoir reprendre le projet sans perdre le contexte.

## Statut actuel

Le socle métier V1 est fonctionnel. Le module de paiement des factures clients et la facturation SaaS sont volontairement reportés.
