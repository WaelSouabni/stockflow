# StockFlow Documentation

Documentation technique et opérationnelle de StockFlow.

## Statut actuel

StockFlow dispose d'un socle V1 fonctionnel : stock, produits/variantes, clients, factures, devis, rôles, onboarding entreprise, multi-tenant, emails transactionnels et préparation production.

La CI GitHub Actions est verte et vérifie notamment Prisma, les tests unitaires, TypeScript, le build et les E2E Playwright.
