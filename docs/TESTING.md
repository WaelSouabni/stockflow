# Stratégie de tests

## Actuel

- Vitest pour les règles métier et tests unitaires
- Playwright pour les parcours navigateur / E2E
- CI GitHub Actions verte

## À renforcer

- Permissions
- Isolation multi-tenant
- Numérotation des factures
- TVA et remises
- Workflow devis → facture
- Stock lié aux factures
- Onboarding
- Paiements
- Facturation SaaS

Chaque fonctionnalité majeure doit idéalement avoir des tests métier et au moins un parcours E2E critique.
